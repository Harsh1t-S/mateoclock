Privacy policy

Mate OClock Uploader · Effective October 31, 2026

This policy covers Mate OClock Uploader, the command-line tool the owner of the Mate O'Clock YouTube channel uses to upload the channel's videos, and this website.

YouTube API Services

Mate OClock Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. How Google handles your data is described in the Google Privacy Policy.

What it accesses

When the channel owner signs in, Google gives the tool an OAuth token with one permission, youtube.upload, which lets it upload videos to the owner's own channel. The tool uses YouTube API Services only to upload videos (videos.insert). It does not read, collect or store any other YouTube or Google account data, and it has no access to anyone else's account.

What it stores

  • The OAuth token, in a file on the owner's own computer.
  • The ID of each video it uploads, in that video's local settings file, so no video is uploaded twice.

Nothing is stored on any server run by Mate O'Clock; there is no such server.

How data is used and shared

The token is used only to send the owner's own videos, titles and descriptions to YouTube. No data is sold, shared with or disclosed to anyone else, inside or outside Mate O'Clock.

Cookies, ads and analytics

The tool shows no ads, lets no third party serve content, and uses no cookies or analytics. This website sets no cookies and loads nothing from other sites. It is hosted on GitHub Pages, which may log technical data such as IP addresses under the GitHub Privacy Statement.

Revoking access and deleting data

You can revoke Mate OClock Uploader's access at any time on Google's security settings page: security.google.com/settings/security/permissions. Revoking it makes the stored token useless, and deleting the local token file removes it entirely. To ask about any data, or to request its deletion, email mateoclockchess@gmail.com.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
